# User Stories

User stories describe **a need from the perspective of a user and the value they expect**.

## US-001 — Story Title

**As a** [type of user]  
**I want** [goal]  
**So that** [benefit/value]

### Acceptance Criteria

- Given [context], when [action], then [expected result].
- Given [context], when [action], then [expected result].
