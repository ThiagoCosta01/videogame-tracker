# Project Vision

## Purpose

Explain why the project exists and the problem it aims to solve.

## Objectives

- Define the primary objective.
- Define secondary objectives.

## Target Audience

Describe the users, customers, or organizations the project is intended for.

## Scope

### In Scope

- Features, processes, or domains included in the project.

### Out of Scope

- Features, processes, or domains explicitly excluded.

## Expected Outcomes

Describe the expected business or user outcomes.

## Example

> Build a patient management system that provides patients with a simple view of appointments, medications, and clinical history.
