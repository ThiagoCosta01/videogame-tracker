# Use Cases

Use cases describe **how an actor interacts with the system to accomplish a specific goal**.

## UC-001 — Use Case Name

**Actor:** [Primary actor]

**Goal:** Describe what the actor wants to accomplish.

**Preconditions:**

- Condition that must be true before the use case starts.

**Trigger:** What starts the interaction.

### Main Flow

1. Actor performs an action.
2. System responds.
3. Actor performs another action.
4. System completes the operation.

### Alternative Flows

- **A1:** Describe an alternative scenario.

### Exceptions

- **E1:** Describe an error or failure scenario.

**Postconditions:** Describe the resulting system state.

**Related Requirements:** FR-001

## Example

> UC-001 — Schedule Appointment
>
> Actor: Patient
>
> Goal: Schedule an appointment with a doctor.
