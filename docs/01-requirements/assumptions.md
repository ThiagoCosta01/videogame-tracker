# Assumptions

Assumptions document **conditions believed to be true when planning or designing the project**. They should be validated because they may prove incorrect.

## ASM-001 — Assumption

**Statement:** Describe the assumption.

**Reason:** Explain why it is being assumed.

**Validation:** Describe how it can be verified.

**Impact if False:** Explain what changes if the assumption is incorrect.
